# bp-tictactoe-example
Example of Behavioral Programming (BP) in Glamorous Toolkit using Gt4Bp: play tictactoe.

## Installation

```st
Metacello new
	repository: 'github://isegorg/bp-tictactoe-example:main/src';
	baseline: 'BpTictactoeExample';
	load
```

## Load Lepiter

After installing with Metacello, you will be able to execute

```
#BaselineOfBpTictactoeExample asClass loadLepiter
```
